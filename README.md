# Raj Tiwari — Portfolio

Personal portfolio built with Next.js and Three.js: a walkable 3D office on the home page, plus a full profile, free browser tools, blog and games.

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
```

## Edit content

All text, links, stats, experience and projects live in `lib/site.js`.
Images are in `public/` (photo: `public/img/raj.webp`, project screenshots: `public/work/`).

## Deploy

Import this repo on [Vercel](https://vercel.com/new); it's detected as a Next.js app with no extra config.
